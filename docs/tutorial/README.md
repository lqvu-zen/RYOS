# RYOS — User Guide

**RYOS (Run Your Own Scripts)** is a lightweight desktop app for saving your scripts and running them with a single click — no terminal, no remembering file paths. You save a script once as a card, then press ▶ to run it and watch its output appear at the bottom of the window. This guide is written for everyday users (not just developers): it walks through the app screen by screen, in the order you'd naturally learn it.

> **About the screenshots.** This guide was written against the live app (window title *RYOS v1.7.6-dev*). Each page has a slot for a screenshot with a caption describing exactly what to capture. The image files (`images/NN-name.png`) are to be added in a follow-up pass — until then you'll see the caption text in their place.
