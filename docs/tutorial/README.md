# RYOS — User Guide

**RYOS (Run Your Own Scripts)** keeps the scripts you run often in one window and runs any of them with one click: no terminal, no remembering where a file lives or which arguments it takes. You add a script once, press its green **▶**, and read what it printed at the bottom of the window. This guide is for everyday users, not just developers; it goes screen by screen in the order you'd naturally learn the app.

Every picture here was captured from the real app (the **Samples** group that ships with RYOS, in the **Light** theme), so what you see is what you'll get.
