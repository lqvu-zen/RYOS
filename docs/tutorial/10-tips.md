# Tips & shortcuts

A few small things that make RYOS faster to use day to day.

- **Drag a file in.** Drag a script from File Explorer onto the RYOS window to open **Add Script** with the path already filled in.
- **Drag cards to organise.** Drag a card up or down to reorder it; drag it onto another group's tab to move it there.
- **Let RYOS pick the interpreter.** Leave the **Interpreter** field blank and RYOS detects the right one from the file extension (`.py` → Python, `.ps1` → PowerShell, and so on). Only fill it in to override.
- **Collapse what you don't need.** Click the ▼ headers on **RUNNING**, **PIPELINES**, and **SCRIPTS** to fold sections, and use **Hide Output** to tuck the panel away.
- **Read the last-run badge.** Each card shows a green **✓ OK** or red **✗ Failed** badge with the time, so you can see at a glance how its last run went — no need to open the output.
- **Use the All tab.** Click **All** in the tab row to see every group's scripts together when you're not sure which group something is in.
- **Presets beat re-editing.** If you keep changing a script's arguments, save them as named **presets** and pick one at run time instead. For truly one-off values, use the **TEMP PARAM** prompt.
- **Stop a runaway script.** The red **⏹** button cancels a running script or pipeline immediately.
- **Back up your setup.** **⚙ → Export all groups** saves everything to a `.json` file you can re-import later or on another machine.
- **Tune the look.** Switch between **Light** and **Dark**, change the accent colour, or pick a **Compact** layout and **Card size** in **Advanced Options → Appearance**.
