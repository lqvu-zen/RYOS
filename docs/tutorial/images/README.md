# Screenshots to capture

Each page references one or more images by these exact filenames. Drop the PNGs here (crop to the RYOS window only — no desktop, taskbar, or other apps) and the pages will render them automatically. Use the **Light** theme and a ~860×700 window.

| File | What to capture |
|---|---|
| `01-main-window.png` | The whole RYOS window: header, group tab, Quick Run bar, a pipeline card, two script cards, collapsed Output bar. |
| `02-add-script-dialog.png` | The **Add Script** dialog, filled in with a believable example. |
| `02-new-card.png` | The SCRIPTS list with a newly added card. |
| `03-run-output.png` | The expanded **Output** panel after a short run: per-run tab, command line, output, green `exit code 0`. |
| `04-group-menu.png` | The group-tab right-click menu (Rename, Clone Group, Base directory…, Export group, Delete Group). |
| `05-parameters-field.png` | The Edit Script dialog with the **Parameters** field filled in. |
| `05-temp-param-prompt.png` | The **Run with temp param** dialog. |
| `06-pipeline-editor.png` | The **Edit Pipeline** dialog with a few steps. |
| `07-quick-run-bar.png` | The Quick Run bar, ideally with an autocomplete suggestion showing. |
| `08-options-menu.png` | The **⚙** Options menu open (Export all groups / Import config visible). |
| `09-appearance.png` | Advanced Options → **Appearance** tab. |
| `09-startup.png` | Advanced Options → **Startup** tab. |
